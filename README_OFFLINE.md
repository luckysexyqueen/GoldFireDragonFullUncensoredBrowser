# GoldFireDragon Browser 오프라인 로컬 환경 가이드

이 프로젝트는 오프라인 로컬 환경에서도 원활하게 작동하도록 수정되었습니다. 모든 외부 라이브러리(A-Frame, Tailwind CSS, Font Awesome 등)와 주요 에셋들이 로컬 폴더로 다운로드되어 포함되어 있습니다.

## 🚀 실행 방법

### 1. 단순 정적 페이지로 실행 (인터넷 불필요)
가장 간단한 방법으로, 브라우저에서 직접 `index.html` 파일을 엽니다.
- **장점**: 별도의 설정이나 서버 구동 없이 즉시 확인 가능합니다.
- **단점**: 검색 기능 및 일부 동적 기능이 제한될 수 있습니다.

### 2. 로컬 서버로 실행 (Node.js 필요)
모든 기능을 온전히 사용하려면 포함된 `server.js`를 구동하는 것이 좋습니다.
1. [Node.js](https://nodejs.org/)가 설치되어 있는지 확인합니다.
2. 터미널(CMD)을 열고 해당 폴더로 이동합니다.
3. 다음 명령어를 입력합니다:
   ```bash
   npm install  # (최초 1회, 필요한 경우)
   node server.js
   ```
4. 브라우저에서 `http://localhost:3000`에 접속합니다.

## 🛠 수정 사항 (오프라인 최적화)
- **CDN 의존성 제거**: `aframe.min.js`, `nipplejs.min.js`, `tailwind.min.js`, `font-awesome` 등을 `lib` 폴더에 로컬화하였습니다.
- **폰트 로컬화**: 외부에서 불러오던 `aCutieHoney` 폰트를 `fonts` 폴더에 포함하고 경로를 수정하였습니다.
- **이미지 로컬화**: 배경 이미지 및 로고 이미지를 `images` 폴더에 포함하였습니다.
- **상대 경로 적용**: 모든 리소스 참조를 상대 경로로 변경하여 `file://` 프로토콜에서도 리소스가 깨지지 않도록 하였습니다.

## ⚠️ 주의 사항
- **검색 기능**: 검색바의 검색 제안(Suggestions) 및 실제 검색 결과는 Google 서버에 의존하므로, 실제 오프라인(인터넷 연결 없음) 상태에서는 작동하지 않습니다.
- **VPN 기능**: VPN 연결 기능은 외부 서버와의 통신이 필요하므로 오프라인 상태에서는 작동하지 않습니다.
- **Puppeteer**: `server.js`를 통해 검색 기능을 사용할 경우, Puppeteer가 브라우저를 실행하므로 인터넷 연결이 필요할 수 있습니다.

## 📁 디렉토리 구조
- `index.html`: 메인 페이지
- `lib/`: 로컬화된 외부 라이브러리 (JS, CSS)
- `fonts/`: 로컬화된 폰트 파일
- `images/`: 로컬화된 이미지 파일
- `server.js`: Node.js 기반 로컬 서버
